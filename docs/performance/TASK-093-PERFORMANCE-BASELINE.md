# TASK-093 浏览器性能基线

日期：2026-10-10

运行方式：TASK-091～093 定向 Playwright Chromium E2E（7 项、1 worker），PNG fixtures 在浏览器 Canvas 中生成并经应用上传，生成使用真实 Worker。

环境：Windows 10 x64，Headless Chromium 151.0.7922.34，`navigator.hardwareConcurrency=12`，`navigator.deviceMemory=32 GiB`。

## 结果

下表为本次串行定向 E2E 运行的观测值。生成耗时从确认裁剪开始计时，至 Editor 路由及 Grid 可见；包含请求准备、图像处理、Worker 生成和成功提交，不是单独算法耗时。

| 样本         | 输入 / 最终 Grid  | 生成耗时 |  Worker RGBA 输入 | 提示与运行状态                                        |
| ------------ | ----------------- | -------: | ----------------: | ----------------------------------------------------- |
| 最小宽度     | 40×30 → 8×6       | 191.7 ms |        未单独记录 | 成功；7 宽被拒绝，8 宽可生成                          |
| 最大宽度     | 40×30 → 256×192   | 341.7 ms |        未单独记录 | 成功；257 宽被拒绝，256 宽可生成                      |
| 极端比例     | 40×4 → 64×6       | 178.2 ms |        未单独记录 | 显示非阻塞比例提示并成功生成                          |
| 常规长边     | 4096×2048 → 64×32 | 599.3 ms | 4096×2048，32 MiB | 无大图提示、无页面运行时错误                          |
| 超过常规长边 | 5000×5000 → 64×64 | 487.7 ms |     64×64，16 KiB | 显示 PRD 大图提示；预处理后生成成功，无页面运行时错误 |

## 内存与限制

本次 Chromium 暴露的非标准 `performance.memory.usedJSHeapSize` 在样本前后均报告 10,000,000 bytes。该 API 是粗粒度 JS heap 观测，不包括可靠的浏览器进程 RSS、图片解码器及 Canvas/GPU 峰值，因此不能据此宣称峰值内存已测得；本基线将峰值进程内存记为“不可用”。

4096×2048 常规样本向 Worker 传入 32 MiB RGBA，表明常规 4096px 级输入仍有明显像素传输成本。超过 TECH 常规 4096px 长边的输入在主线程只读取最终 bead-grid 尺寸的 crop RGBA；原始 Blob 和作品裁剪/旋转配置不变。浏览器仍须解码源图片，极端输入的浏览器原生解码内存未由 JS heap API 捕获。

PRD 上传提示阈值仍保持为像素数大于 24,000,000 或长边大于 8192px；该提示规则与生成预处理阈值独立。生成预处理从长边超过 4096px 开始，遵循 TECH §16.2，不构成上传拒绝条件，也没有新增 Grid 总格数上限。宽度产品边界仍是 8～256；极端比例继续提示但允许生成。

## 工程结论

- 本机 Headless Chromium 对宽度边界、极端比例、4096px 常规长边及 25MP 输入均完成了可见的真实 Worker 生成；本轮无生成失败、页面错误或静默卡死。
- 超过 4096px 长边的路径避免在主线程建立完整源图 RGBA 数组和第二份完整裁剪数组；5000×5000 用例的 Worker 输入从源图 100,000,000 bytes 等效 RGBA 降至 16,384 bytes。
- 当前数据只代表本测试环境的一次自动化观测，不是低端设备的性能承诺。峰值原生内存、低端设备耗时和更极端输入的浏览器解码失败仍需在目标设备验证；生成异常由现有失败流程呈现，当前 Project/Grid 不因失败被替换。
- 本任务没有把性能结果转化为新的产品硬限制。后续 TASK-094 应继续测量大 Grid 下 Worker 与 Canvas 并发交互，并采用能观测浏览器进程/原生内存的目标设备工具补齐峰值数据。
